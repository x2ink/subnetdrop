The first emulator run exposed an `NsdManager` crash caused by reusing one `ResolveListener` for duplicate discovery callbacks. The implementation now deduplicates active service resolution, creates one listener per request, and retains a service-to-peer mapping for reliable loss events. The rebuilt APK remained alive after registration and rendered the expected online screen without an `AndroidRuntime` exception.

The first macOS run exposed a desktop secure-storage bug: `java-keyring` reports a missing first-use credential with a
`PasswordAccessException`, not `null`. The adapter now recognizes only the documented macOS missing-item condition and
Windows error 1168. Permission failures and other keychain errors remain visible. After the fix, the process listened on
TCP `45892`; both HPKE and Ed25519 private-key entries existed in macOS Keychain without reading their secret values.

The physical phone at `192.168.21.100` discovered and paired with the macOS client. One incoming and one outgoing message
were displayed as delivered. The desktop SQLite database independently contained one `INCOMING/DELIVERED` and one
`OUTGOING/DELIVERED` record. Restarting the desktop app restored its identity, history, and listener.

The desktop UI was visually checked at its default `1180 x 760` size and a compact `480`-pixel-wide layout. Navigation
stays at the bottom, independently sized lists remain scrollable at short heights, conversation rows show unread badges,
and outgoing bubbles distinguish `未读` from `已读`.

The first newly packaged desktop application exposed a missing `java.sql` module in the bundled runtime. Gradle runtime
module analysis identified the complete module set; the distribution now declares it explicitly. The rebuilt DMG was
installed, launched successfully, and remained listening on TCP `45892`. No Android build or installation was run during
this iteration.

The file-transfer build was installed to `/Applications/ink.x2.kmp.app`, launched successfully, and listened on TCP
`45892`. The desktop UI exposes a paperclip action beside the composer while the message list remains scrollable.
Integration tests transferred a deterministic 70,000-byte file over three encrypted chunks, compared the received bytes,
and separately verified that rejecting an offer created no destination directory or file.

The installed desktop application was visually checked with an incoming one-character message (`1`), an incoming short
message and an outgoing message containing delivery state. A shared 64 x 48 dp minimum bubble size prevents corner
compression, while the fixed 14 dp corners remain unchanged as content grows. The application continued listening on TCP
`45892`; this verification did not build or install Android.
